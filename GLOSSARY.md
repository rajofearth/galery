# Galery

Galery is a local media browser for Android. It reads photos and videos already on the device and presents them without an account, cloud service, or network dependency.

## Language

**Galery**:
The application itself. The single 'l' in the name is intentional. It is not a collection of media.
_Avoid_: Gallery, app, photo app, library

**Media item**:
One photo or video that Gallery presents. Use this when the kind of media does not matter.
_Avoid_: File, asset, media file

**Photo**:
A still-image media item.

**Video**:
A media item that plays over time.

**Album**:
A group of media items that share a folder on the device, such as Camera or Downloads. v1 uses folders and ignores EXIF albums.
_Avoid_: Folder, bucket, EXIF album

**All media**:
The virtual view that contains every media item on the device. It is not an album.
_Avoid_: Library, all photos

**Favorite**:
A media item the user marks for quick access.

**Viewer**:
The full-screen screen that shows one media item.
_Avoid_: Detail screen, photo page

**Mosaic**:
The default media layout. Each tile keeps its item's aspect ratio inside an equal-height row.

**Grid**:
The alternate media layout. Tiles are square-cropped and share one size.
_Avoid_: Square grid, uniform grid
