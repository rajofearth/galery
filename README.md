# Galery

A local photo and video gallery for Android. No account, no cloud, no ads. Built with Kotlin and Jetpack Compose.

## Status

The buildable shell is in place. The repository also holds the product glossary, deferred scope, and architecture decision records in `docs/adr/`. Media access, the mosaic, and the Viewer are still to come.

## Planned features

- Aspect-preserving mosaic with a toggle to a square grid
- Albums from device folders
- Full-screen viewer with swipe, zoom, and muted video playback
- Multi-select with share, favourite, delete, and details
- Search by filename, album, and date
- Material 3 Expressive with dynamic colour
