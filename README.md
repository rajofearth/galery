# Galery

A local photo and video gallery for Android. No account, no cloud, no ads. Built with Kotlin and Jetpack Compose.

## Features

- Aspect-preserving mosaic with a toggle to a square grid
- Albums from device folders
- Full-screen Viewer with swipe, zoom, and muted video playback
- Favorites and multi-select with share, move to trash, and details
- Search by filename, album, and date
- Date browsing by year, month, and day, with a floating glass dock

System trash is available on Android 11 and later.
